# Sample papers

Drop your own `.pdf`, `.txt`, or `.md` files here, then run:

```bash
python main.py sample_papers
```

The pipeline picks up every supported file in this directory.

## Where to get openly-licensed test papers

If you don't have papers handy and want to try the pipeline, the
sources below publish under licenses that explicitly allow
redistribution and reuse:

- **[arXiv](https://arxiv.org/)** — preprints across CS, physics, math, etc.
  Most papers are submitted under licenses that permit redistribution;
  always check the individual paper's license metadata.
- **[PLoS journals](https://plos.org/)** — biology, medicine, computational
  biology; all articles are CC-BY licensed.
- **[PubMed Central Open Access subset](https://www.ncbi.nlm.nih.gov/pmc/tools/openftlist/)** —
  hundreds of thousands of biomedical full-text papers under
  redistributable licenses.
- **[MDPI](https://www.mdpi.com/)** — open-access publisher across many
  fields; articles are CC-BY.
- **[DOAJ](https://doaj.org/)** — directory of peer-reviewed open-access
  journals, filterable by license.

Pick 2–6 papers on a related topic, drop the PDFs in this folder, and
you'll get a synthesis report comparing them.

## Why this folder is empty

The repo ships without sample papers to avoid redistributing copyrighted
material. Most journal articles are owned by their publishers, not the
authors — sharing them in a public repo is technically a copyright
violation even when intended for educational use. Bring your own.
